# Публикация Argus: что и куда загружать

Всё готово к публикации, кроме двух вещей, которые нужны только от владельца:
**ник на GitHub** и **токен бота Telegram** (для проверки алертов на живом сервере).

## 1. GitHub

**Имя репозитория:** `argus` (или `minecraft-argus` — если `argus` уже занят в твоём аккаунте)

**Описание репозитория (одной строкой):**

> Watchdog and auto-healer for Paper servers — finds the cause of lag, fixes it, and reports to Telegram. Free, MIT, no telemetry.

**Topics:**

```
minecraft paper plugin performance watchdog lag telegram minecraft-server
java minecraft-plugin server-utility optimizer folia
```

**Команды:**

```bash
git remote add origin https://github.com/<ТВОЙ_НИК>/argus.git
git push -u origin main
```

### 2.1 Описание проекта (markdown, вставлять в поле Description)

```markdown
## Argus

**Находит причину лагов, устраняет её и пишет об этом в Telegram.**

Сервер начал лагать в 3 часа ночи. Вы узнаёте об этом в 9 утра — от злых игроков.
Или не узнаёте вообще, и сервер тихо умирает неделями.

Argus снимает метрики каждые несколько секунд и, когда что-то идёт не так:

1. **Называет причину** — падение TPS, нехватка тиков, нехватка памяти, поток сущностей,
   поток чанков. С цифрами, которые это доказывают.
2. **Устраняет её** — выгружает виновный чанк, чистит кучу, временно отключает автосохранение.
   По умолчанию только обратимые действия; разрушительные включаются вручную.
3. **Сообщает вам** — сообщение в Telegram с диагнозом и списком того, что было сделано.

Отдельно плагин ищет **конкретный виновный чанк**, обходя загруженные чанки небольшими
шагами, — так, чтобы сам скан не стал той лагой, которую он ищет.

## Ключевые особенности

- **Одна тревога на инцидент**, а не одна на каждый замер. Одиночный всплеск не вызовет её.
- **Только обратимые действия по умолчанию.** `remove_entities` и `restart_server` выключены.
- **Ноль зависимостей в рантайме.** Telegram — обычный HTTPS через HTTP-клиент из JDK.
- **Никакой телеметрии.** Наружу уходят только те данные, что перечислены в сообщении.
- **Не трогает данные игроков.** Ни инвентарей, ни логов, ни статистики по игрокам.
- **Бесплатно навсегда.** Нет платных версий, нет апселлов, нет скрытых платежей.

## Установка

1. Скачайте JAR со страницы проекта.
2. Положите в `plugins/`.
3. Запустите сервер — плагин работает сразу, без Telegram он просто пишет в лог.

### Настройка Telegram (по желанию)

1. Создайте бота через [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Напишите боту и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Возьмите из ответа ваш `chat.id`.
4. Впишите в `config.yml`:

```yaml
telegram:
  bot_token: "123456:ABC-DEF..."
  chat_id: 987654321
```

5. `/argus reload`

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/argus status` | `argus.use` | Текущие TPS, время тика, куча, игроки, сущности, чанки, активные проблемы |
| `/argus history` | `argus.use` | Последние 10 инцидентов |
| `/argus scan` | `argus.use` | Принудительно найти виновный чанк прямо сейчас |
| `/argus reload` | `argus.admin` | Перечитать `config.yml` и применить новые пороги |

## Настройка

Всё в `config.yml`. Значения по умолчанию рассчитаны на сервер 4–8 ГБ.

```yaml
sample:
  interval_ticks: 100        # 100 тиков = 5 секунд между замерами
thresholds:
  warn_mspt: 45.0
  critical_mspt: 70.0
  warn_tps: 17.0
  critical_tps: 12.0
  warn_heap_ratio: 0.80
  critical_heap_ratio: 0.92
  max_entities: 3000
  max_chunks: 4000
  samples_before_alarm: 3
```

## Требования

- Paper 1.21.x или новее (плагин проверен на 1.21.x; на более новых грузится за счёт `api-version: '1.21'`)
- Java 21

## Что Argus не делает

- Ничего не отправляет наружу, кроме настроенного чата Telegram.
- Ничего не знает про игроков и их данные.
- Ничего не рекламирует.
- Ничего не стоит.

## 5. Первые пользователи

Руками, а не рекламой. Нужно 20–30 серверов, на которых плагин постоит пару недель:

- свой тестовый сервер (с лаг-фермой) — обязательно, это даёт материал для GIF
- 10–15 серверов из знакомых / из чатов, где вы уже общаетесь (в **своём** чате, не в пиар-чатах)
- по одному вопросу в каждом: «что за плагин, покажи скрин» — это даст обратную связь и отзывы

**Не рекламировать в пиар-чатах.** В вашей аудитории это вызывает ровно ту реакцию,
которую видно в комментариях: «опять рекламная помойка». Плагин распространяется через
Modrinth, GitHub и сарафан — это медленнее, но даёт нормальных пользователей.
